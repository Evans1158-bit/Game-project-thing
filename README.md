# CLI App



**The project brief is in [PROJECT.md](./PROJECT.md).** 

This is a rock paper scissors game for my CLI project that somehow works(Thank God) after a little bit of hassle. It is mainly just you going from main to the menu where you have three choices, start, stats, and leave. Start actually lets you play the game, stats lets you check your stats, and leave lets you leave. the thing is in data if Stats don't work then I either forgot to fix it or was too scared to touch the code so if I do fix it then yippee. When you get into the actual game, you face of against a computer in a game of Rock paper scissors, this is luck based, if you win then you get a point but if the computer wins then the computer gets a point.
